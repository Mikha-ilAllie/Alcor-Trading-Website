# Alcor Trading Website

Official business website for **Alcor Trading**, a South African supplier of automotive exhaust performance products and components.

## About the Project

This website was developed to showcase Alcor Trading's range of automotive performance products through a modern, responsive, and user-friendly interface.

## Website Features

- Responsive design for desktop and mobile devices
- Product categories and filtering
- Dedicated pages for performance downpipes, exhaust systems, and components
- Product images and vehicle compatibility information
- WhatsApp enquiry integration
- Downloadable PDF product catalogue
- Contact information and business enquiries

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

- `index.html` – Homepage
- `Downpipes.html` – Performance downpipes
- `Exhaust-Systems.html` – Exhaust performance systems
- `Exhaust-Components.html` – Exhaust performance components
- `style.css` – Website styling
- `script.js` – Website functionality
- `images/` – Product images and website assets
